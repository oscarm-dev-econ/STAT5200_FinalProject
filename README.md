# Replication of Pearson (2024): The Impact of Immigration Status on Crime Reporting

**STAT 5200 — Applied Econometrics**

This repository contains Python scripts replicating selected results from:

Pearson, Thomas (2024). "The Impact of Immigration Status on Crime Reporting: Evidence from DACA." *Journal of Urban Economics*, 143, 103670.

- [Original paper](https://doi.org/10.1016/j.jue.2024.103670)
- [Original replication package (Mendeley Data)](https://data.mendeley.com/datasets/vnyw56mgf3/1)

The replication focuses on the baseline difference-in-differences estimates, heterogeneous treatment effects, placebo tests, and event-study analysis. An additional script implements random forests to predict noncitizen childhood arrival status.

## 1. Download the required datasets

Two datasets are required to run all four scripts.

### A. National Crime Victimization Survey (NCVS)

**Source:** [ICPSR/NACJD — National Crime Victimization Survey](https://www.icpsr.umich.edu/web/NACJD/series/95)

1. Open the NCVS collection page linked above.
2. Locate the annual **NCVS Record-Type Files** for each year from **2005 through 2017**, inclusive.
3. For each year, download the following three datasets in Stata (`.dta`) format:
   - Household Record-Type File (typically DS2)
   - Person Record-Type File (typically DS3)
   - Incident Record-Type File (typically DS4)
4. Extract the downloaded files and rename them according to the following convention:
   - `2005_hhd.dta`
   - `2005_person.dta`
   - `2005_incident.dta`
5. Repeat for every year through 2017, replacing the year in each filename.

A total of **39 NCVS files** are required.

### B. American Community Survey (IPUMS ACS)

**Source:** [IPUMS USA](https://usa.ipums.org/usa/)

1. Create an IPUMS USA account or log in.
2. Open the [Sample Selection page](https://usa.ipums.org/usa-action/samples).
3. Select the annual **ACS 1-year samples for 2005–2017**.
4. Select the following variables:

   `YEAR`, `AGE`, `SEX`, `MARST`, `EDUC`, `EDUCD`, `HISPAN`, `RACED`, `REGION`, `METRO`, `OWNERSHP`, `HHINCOME`, `CITIZEN`, `BIRTHYR`, `YRIMMIG`, `PERWT`

5. Submit the extract request and download the data when available.
6. Obtain the corresponding Stata dataset using the IPUMS-provided data and syntax files, if necessary.
7. Save the combined extract as **`usa_00007.dta`**.

The resulting file contains approximately 39.9 million observations before sample restrictions. After selecting Hispanic respondents with at least a high school education, the sample should contain **2,424,297 observations**.

## 4. Run the replication scripts

Run the scripts from the project directory in the following order.

### Stage 1 — Baseline difference-in-differences (Table 2)

```bash
python code/stage1Replication.py
```

This script reads the annual NCVS files and the ACS extract, constructs the baseline incident-level sample, and estimates the six specifications in Table 2.

**Expected outputs:**

- ACS Hispanic HS+ sample: 2,424,297
- Baseline NCVS sample: 5,364 incidents
- Mean reporting rate: 0.408
- Unadjusted DiD estimate: 0.0518
- Preferred regression coefficient (column 3): 0.0834
- Clustered standard error: 0.0437

Results are printed in the terminal.

The script also saves:

`data_processed/pearson_table2_baseline.pkl`

This file is required for Stages 2 and 4.

### Stage 2 — Heterogeneity, placebo tests, and event study (Tables 1 and 3; Figures 1 and 2)

```bash
python code/stage2Replication.py
```

This script uses the baseline dataset produced in Stage 1 and additional NCVS observations to reproduce:

- **Table 3:** Heterogeneous effects by gender, educational attainment, and home ownership.
- **Table 1:** Placebo tests using a hypothetical 2008 DACA implementation.
- **Figure 1:** Reporting trends among age-eligible and age-ineligible Hispanic and white non-Hispanic victims.
- **Figure 2:** Event-study estimates of the effect of DACA eligibility.

Table 1 and Table 3 results are printed in the terminal.

The script saves:

```text
data_processed/
    pearson_stage2_extended_reporting.pkl

outputs/figures/
    figure1_reporting_trends.png
    figure2_event_study.png
```

Stage 2 automatically reuses the extended processed dataset if it already exists. Delete the cached `.pkl` file to reconstruct the data from the original NCVS files.

### Stage 3 — Placebo tests across demographic groups (Figure 3)

```bash
python code/stage3Replication.py
```

This script estimates the effects of DACA eligibility on crime reporting among three groups unlikely to benefit directly from the policy:

- Hispanics without a high school degree
- Black non-Hispanics
- White non-Hispanics

The coefficients, clustered standard errors, reporting means, and sample sizes are printed in the terminal.

The script saves:

`outputs/figures/figure3_reporting_placebos.png`

### Stage 4 — Random forests and predicted immigration status (Table 4)

```bash
python code/stage4Replication.py
```

This script uses IPUMS ACS data to train 13 annual random forest classifiers, each with 100 trees, and applies them to NCVS respondents to predict the probability of being a noncitizen childhood arrival.

The predicted probabilities are then used to estimate the heterogeneous effects reported in Table 4.

**Expected sample benchmarks:**

- ACS Hispanic HS+ respondents: 2,424,297
- NCVS Hispanic HS+ person-surveys: 186,810
- Baseline reporting incidents: 5,364

The script saves:

```text
data_processed/
    pearson_ncvsperson_rf_predictions.pkl
    pearson_table4_with_predictions.pkl
```

The random forest predictions are cached to avoid retraining the models on every run. Set `retrain_forests = True` to rerun the training.

Stage 4 is optional for reproducing the main NCVS difference-in-differences results.

## 5. Replication results and known differences

| Result | Replication outcome |
|---|---|
| Table 2 | All six coefficients, clustered standard errors, and sample sizes closely match the published results. |
| Table 3 | All six heterogeneous-effect regressions closely match the published results. |
| Table 1 | All four placebo estimates are statistically insignificant, consistent with the paper, but the sample contains 3,552 rather than 3,654 observations. |
| Figure 1 | Reproduced reporting trends by age eligibility. |
| Figure 2 | Reproduced event-study estimates and confidence intervals. |
| Figure 3 | Reproduced placebo regressions for groups unlikely to benefit directly from DACA. |
| Table 4 | Baseline sample and predicted-probability distributions are similar to the original; subgroup results differ from those published. |

The Table 1 sample-size discrepancy was investigated and traced to differences involving incidents from 2005–2006, although the exact source of the difference remains unresolved.

The principal replication results of interest are the baseline difference-in-differences estimates, heterogeneous effects by observable characteristics, event-study results, and placebo tests.
